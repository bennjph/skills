# Design: Elite Deck Process

This workstream defines the design sense the skill should encode.

## The role

The target is not a generic slide generator. The target is an elite deck designer's working method translated into agent behavior.

That means the skill should behave like someone who can do all of the following:

- understand the business purpose
- challenge weak structure
- reduce cognitive load
- choose a visual system that matches the message
- turn the result into an editable, resilient document

## Process

### 1. Clarify purpose

- What decision is this deck trying to move?
- What does the audience already believe?
- What resistance or skepticism will show up?
- What is the presenter asking for at the end?

### 2. Clarify audience

- executive
- investor
- technical reviewer
- customer
- internal team

Audience changes everything: pacing, evidence density, terminology, chart depth, tone, and visual polish.

### 3. Lock the message

- define the single controlling idea
- identify the minimum story needed to support it
- remove slides that explain interesting things but do not move the case

### 4. Choose the visual system

- formal and analytical
- product-forward and modern
- cinematic keynote
- workshop or collaborative review

Do not let visual style float independently from message type.

### 5. Design the slide types

- opener
- section divider
- evidence slide
- chart slide
- comparison slide
- process slide
- recommendation slide
- appendix

Each slide type should have clear rules for hierarchy, density, and motion.

## Taste rules

- Prefer asymmetry with strong alignment over bland symmetry.
- Prefer decisive typography over default software styling.
- Prefer white space that sharpens reading over decorative emptiness.
- Prefer native charts styled with restraint over handmade fake charts.
- Prefer one memorable visual idea per section over constant novelty.

## Anti-slop rules

- No random icon rows.
- No three-column boxes unless the content genuinely calls for them.
- No generic startup gradients as a default mood.
- No bullet stacks that merely restate the section title.
- No slide that exists only because "decks usually have one of these."

## Quality signals

- Titles alone reveal the argument.
- The deck feels paced, not dumped.
- Data is easy to read without over-decoration.
- Motion feels intentional or absent, never accidental.
- A designer or operator can update the file without breaking it.

## Standard heuristics

- one message per slide
- action-title discipline
- high signal-to-noise ratio
- consistent grid and margin system
- appendix for overflow, not main-story clutter

## What the skill should enforce

- a design choice must be justified by audience, message, or data
- visual density must match speaking time
- style escalation should happen only on high-stakes moments
- narrative clarity wins over showing off design range
